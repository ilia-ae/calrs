Новый тип встречи

В режиме «По очереди» встреча назначается одному свободному участнику (сначала наименее занятому). В режиме «Совместная» все участники должны быть свободны в одно и то же время.
Показывается на странице записи. Можно использовать **жирный**, *курсив* и [ссылки](url).
Необязательный шаблон вместо стандартного. Переменные: {username}, {event}, {date}, {random}. Оставьте пустым, чтобы использовать шаблон организации, заданный администратором. В этом шаблоне нет переменной {random}. Две записи этого типа встречи в один день попадут в одну и ту же комнату, и второй гость сможет зайти на встречу первого. Используйте постоянные комнаты, только если вам нужно именно это. Ссылка на встречу для каждой записи запрашивается у вебхука, который администратор настроил в разделе «Панель администратора → Вебхук для встреч». Указывать адрес здесь не нужно. Уникальная ссылка Google Meet создаётся при подтверждении записи, её владелец — назначенный организатор. У каждого организатора (у вас или у каждого подходящего участника команды) должен быть подключён Google Calendar и выбран календарь для новых записей.
С каким шагом предлагать время. Если не заполнено, шаг равен длительности.

Приоритет участников

Новые записи в первую очередь получают свободные участники с более высоким приоритетом. При равном приоритете запись получает тот, у кого меньше недавних записей.

Доступность
Часы ниже указаны в этом часовом поясе. Для командных типов встреч выберите рабочий часовой пояс команды (он может не совпадать с вашим).
Часы взяты из вашей доступности по умолчанию. Здесь их можно изменить для этого типа встречи.

Бесплатно
Текущая лестница: бесплатно → 20 → 40 → 60 → 80 → 100 → 200 → 300 → 400 → 500 TON
Цена — ступень, соответствующая числу ваших предстоящих записей на ближайшие дни (подтверждённых или оплаченных, бесплатных заявок, ждущих вашего подтверждения, и командных записей, которые ведёте вы; неоплаченные не считаются): сначала бесплатно (каждую бесплатную запись вы подтверждаете сами), затем выше по мере заполнения календаря.
